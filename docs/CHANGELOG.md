# 当前版本记录

## 0.4.14

- 脱敏诊断增加最近约 30 分钟的系统与应用资源采样，可保留上次运行记录。
- 增加“标记卡顿”，便于把故障发生时刻与 CPU、内存、页面响应和请求状态对应起来。
- 汇总后台和公开网页请求的阶段、错误及等待情况，不保存请求地址、页面正文、请求头或登录凭据。
- 导出时补充 Windows 分页、磁盘、匿名网卡计数及 Edge/Chrome 进程资源情况；不可用的项目不阻塞导出。
- 诊断数据通过白名单重建，不导出密钥、自定义模型名称或原始任务标识。

该版本延续：启动时恢复标签但暂不加载；支持暂停后台网页并保留登录；新建页面默认打开抖店主页；AI 任务按用户需求触发。

原交付验证包含 193 项单元测试、TypeScript/Vite 构建、打包后的诊断导出与隐私检查，以及增量更新的版本和文件校验。客户电脑的卡顿原因尚需真实诊断证据，不能从开发机测试推定已解决。
